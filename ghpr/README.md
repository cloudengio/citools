# [cloudeng.io/citools/ghpr](https://pkg.go.dev/cloudeng.io/citools/ghpr?tab=doc)


Usage of `ghpr`

    create and maintain github pull request descriptions with an ai agent

         create-pr - create a pull request for the current branch, with a description generated from its diff
    update-summary - regenerate the description of a pull request from what its branch now changes
         post-note - attach the description of a merged pull request to the commit it created on the base branch
            config - config related commands

global flags: [--base=main --config=config.yaml,ghpr.yaml --dry-run=false
--engine=claude --max-diff-lines=3000 --model= --show-command=false
--show-summary-command=false --verbose=false --yes=false]

    -base string
      branch that pull requests are merged into (default "main")
    -config value
      YAML configuration file; if unset, the first of config.yaml and `ghpr`.yaml
      found in the standard locations is used (default config.yaml,ghpr.yaml)
    -dry-run
      report what would be changed without changing it
    -engine string
      agent used to generate descriptions: claude or agy (default "claude")
    -max-diff-lines int
      summarize the diff stat instead of the diff once it is longer than this;
      0 for no limit (default 3000)
    -model string
      model for the agent to use; the agent's own default if unset
    -show-command
      show the command that would be run to generate the summary
    -show-summary-command
      show the command that would be run to generate the summary
    -verbose
      explain what is being done
    -yes
      answer yes to every confirmation

`ghpr` creates and maintains the descriptions of GitHub pull requests using an
ai agent, and records them in the git history.

It is built around this workflow: branch off the base branch, commit as
often as you like locally, push the branch, and raise one pull request that
is squash merged. The description of that pull request is the only account
of the change that survives the squash, so `ghpr` generates it from the diff,
keeps it current, and once the pull request is merged attaches it as a git
note to the single commit it produced:

    `ghpr` create-pr 'chore: update deps'   # on the feature branch
    `ghpr` update-summary                   # after pushing more commits to it
    git switch main
    `ghpr` post-note --delete-branch my-feature

The description is generated by claude or agy, which are run with the diff
and without permission to use tools, so that they summarize the change they
are given and nothing else.
